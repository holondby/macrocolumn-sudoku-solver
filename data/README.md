# Data Directory

This directory contains the Sudoku puzzle data, train-test split information, stress-test puzzle files, and raw solver outputs used for the experiments reported in the manuscript:

**Learning to Search with a Simulated Cortical Macrocolumn**

The files in this directory are provided to support reproducibility of the reported training, evaluation, learning-rate comparison, and statistical-summary results.

## Directory Structure

The intended organization of this directory is:

```text
data/
    README.md
    puzzles/
        train/
        test/
        stress_tests/
    splits/
        train_test_split.txt
    raw_outputs/
        learning_rate_comparison/
        training_set/
        test_set/
```

## Puzzle Files

The `puzzles/` directory contains the Sudoku input files supplied to the solver.

The `puzzles/train/` directory contains the training puzzles used during learning. The `puzzles/test/` directory contains the held-out test puzzles used to evaluate whether learned search guidance transferred to puzzles not used for training.

The 75/25 training-test split was implemented by placing the training and test puzzles in separate directories and supplying those directories to the solver during the corresponding training and evaluation runs.

Puzzle files use `0` to denote an empty Sudoku cell unless otherwise stated in the file itself.

## Train-Test Split

The `splits/` directory records the fixed train-test split used in the manuscript.

The file `train_test_split.txt` should identify which puzzles were assigned to the training set and which were assigned to the held-out test set. The split should not be regenerated when reproducing the reported results, because the manuscript results are based on this fixed partition.

The held-out test set was used with learning disabled and exploration set to zero, so that test-set performance reflected the learned Q-values rather than continued training or random exploration.

## Stress-Test Puzzles

The `puzzles/stress_tests/` directory contains the difficult Sudoku puzzles used for the learning-rate comparison experiments. These include the AI Escargot and Everest puzzles.

These puzzles were used to compare learning rates of 0.01, 0.001, and 0.0001 across the first 50 learning trials, with performance assessed primarily by backtrack count.

## Raw Output Files

The `raw_outputs/` directory contains unprocessed output files generated by the solver.

These files preserve the numerical results used to create the manuscript’s descriptive statistics, statistical tests, tables, and figures. Depending on the experiment, the raw outputs may include backtrack counts, move attempts, maximum selected domain size, contradiction counts, elapsed time, trial number, puzzle identifier, learning rate, and evaluation condition.

The `raw_outputs/learning_rate_comparison/` directory contains results for the learning-rate comparison experiments.

The `raw_outputs/training_set/` directory contains output files from training-set analyses.

The `raw_outputs/test_set/` directory contains output files from held-out test-set evaluations, including trial-0 baseline results and results obtained after loading trained checkpoints.

## Notes on Reproducibility

The data files in this directory should be used together with the source code, scripts, and reproducibility notes provided elsewhere in the repository.

To reproduce the manuscript results, use the fixed puzzle files and train-test split supplied here. Do not reshuffle or replace the puzzle files unless conducting a new analysis not intended to reproduce the reported manuscript results.

The raw output files should be retained unchanged, because they document the numerical results from which the manuscript tables and figures were generated.
